# English Kids — קורס אנגלית לילדים עולים לכיתה ה'

אתר לימוד אנגלית לילדים בגיל 10, בעברית, עם 8 שיעורים קצרים (כ-15 דקות כל אחד).
אתר סטטי לגמרי — בלי שרת, בלי התקנות ובלי הרשמה.

## הפעלה

**הכי פשוט:** לפתוח את `index.html` בלחיצה כפולה. הכל עובד, כולל השיעורים,
ההקראה והמשחקים.

**מומלץ (מפעיל גם את תרגול הדיבור):** להריץ שרת מקומי, כי דפדפנים חוסמים
גישה למיקרופון בקבצים מקומיים:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

**פרסום באינטרנט:** אפשר להעלות את התיקייה כמו שהיא ל-GitHub Pages
(Settings → Pages → Deploy from branch), ולקבל כתובת שאפשר לפתוח מכל מכשיר.

## מה יש בקורס

8 שיעורים, כל אחד עם אותו מבנה של 5 שלבים:

| # | שיעור | נושא | משחק מסכם |
|---|-------|------|-----------|
| 1 | Family & Me | משפחה ואני | התאמה |
| 2 | My House | הבית שלי | התאמה |
| 3 | Food & Drinks | אוכל ושתייה | תמונה למשפט |
| 4 | School Stuff | ציוד לבית ספר | השלמת מילה |
| 5 | Animals | חיות | התאמה |
| 6 | Body & Feelings | גוף ורגשות | תמונה למשפט |
| 7 | Colors, Numbers & Weather | צבעים, מספרים ומזג אוויר | התאמה |
| 8 | My Day | היום שלי | השלמת מילה + סיכום קורס |

**חמשת השלבים בכל שיעור:**

1. **חימום** — חזרה על 2-3 מילים מהשיעורים הקודמים (spiral learning).
   בשיעור 1 מוצגת במקום זה הצצה למילים של היום.
2. **מילים חדשות** — לימוד 6-7 מילים עם תמונה והקראה, ואז בדיקת זכירה.
3. **משפטים** — 4 משפטים עם תרגום והקראה, ואז שאלות הבנה.
4. **תרגול דיבור** — הילד/ה אומר/ת את המשפט למיקרופון והמערכת בודקת.
5. **משחק מסכם** — ואחריו מסך סיכום עם פידבק ופריט חדש לדמות.

**כלל טעות אחיד:** ניסיון אחד לכל שאלה. טעות אף פעם לא חוסמת ולא מחזירה
לאותה שאלה — המערכת מציגה מיד את התשובה הנכונה בצורה חיובית ("כמעט!
התשובה הנכונה: dog") וממשיכה. מילים שהוחמצו נאספות ומחכות לתרגול נפרד
במסך "המסלול שלי".

## הדמות המלווה

בכניסה הראשונה בוחרים אחת מ-10 דמויות (שועל, ארנב, פינגווין, דרקון,
חתלתול, כלבלב, ציפור, פנדה, קוף, חד-קרן) ונותנים לה שם. הדמות מלווה את
כל המסכים ומקבלת פריט חדש בסוף כל שיעור: כובע, צעיף, משקפיים, תיק גב,
מדליה, בלון, סמל כוכב, וכתר בסיום השיעור השמיני.

## כמה ילדים

המערכת תומכת בכמה פרופילים על אותו דפדפן (למשל אחים). כל פרופיל עם דמות,
שם והתקדמות משלו. אין סיסמאות ואין הרשמה — רק בחירה מרשימה.
ההתקדמות נשמרת ב-`localStorage` של הדפדפן, כלומר היא מקומית למכשיר
ולדפדפן שבו לומדים.

## תמיכה בדפדפנים

| יכולת | דרישה |
|-------|-------|
| שיעורים, משחקים, שמירת התקדמות | כל דפדפן מודרני |
| הקראה קולית (Text-to-Speech) | כל דפדפן מודרני |
| תרגול דיבור (זיהוי דיבור) | Chrome / Edge / Safari, חיבור לאינטרנט, הרשאת מיקרופון, וכתובת `http://localhost` או `https` |

כשזיהוי הדיבור לא זמין — שלב הדיבור לא מוצג כלל, והשיעור עובר ישירות
מהמשפטים למשחק המסכם. אם המיקרופון נחסם באמצע, המערכת מדלגת על שאר השלב
במקום להיתקע.

זיהוי הדיבור מכוון להיות סלחני: הוא משווה מילות תוכן עם התאמה מקורבת
ומתעלם מ-`a`/`the`/`please`, כדי לא להעניש הגייה לא מושלמת של ילד.

## עריכת תוכן

התוכן נמצא ב-`data/lesson-N.json` ואפשר לערוך אותו ישירות — הוספת מילה,
שינוי משפט או החלפת משחק לא דורשים נגיעה בקוד.

אחרי כל שינוי בקבצי ה-JSON כדאי להריץ:

```bash
node tools/build-lessons.js
```

זה מרענן את `data/lessons.bundle.js`, שהוא הגיבוי שמאפשר לפתוח את האתר
כקובץ מקומי. בלי זה, פתיחה מהשרת תציג את התוכן החדש אבל פתיחה בלחיצה
כפולה תמשיך להציג את הישן.

### מבנה שיעור

```json
{
  "lessonId": 1,
  "title": "Family & Me",
  "titleHe": "משפחה ואני",
  "introHe": "היום נלמד לדבר על המשפחה שלנו באנגלית!",
  "reviewWords": ["family", "mother"],
  "newWords": [
    { "id": "mother", "en": "mother", "he": "אמא",
      "imagePrompt": "cartoon icon of a smiling mother", "audioText": "mother" }
  ],
  "sentences": [
    { "id": "s1", "en": "This is my mother.", "he": "זאת אמא שלי.",
      "matchImagePrompt": "cartoon icon of a smiling mother",
      "matchWordId": "mother", "distractorWordIds": ["father", "brother"] }
  ],
  "speakingPrompts": [
    { "id": "sp1", "promptHe": "תגיד/י: זאת אמא שלי",
      "expectedPhrase": "this is my mother",
      "acceptableVariants": ["this is my mom", "that is my mother"] }
  ],
  "game": { "type": "matching", "wordIds": ["mother", "father", "brother"] }
}
```

הערות:

- `matchWordId` הוא מזהה האייקון שמוצג בפועל; `imagePrompt` ו-`matchImagePrompt`
  הם תיאורים מילוליים של התמונה, ומשמשים כתיעוד למי שירצה להחליף את האיורים.
- `reviewWords` מפנה למזהי מילים מכל שיעור קודם (ומ-`extra-words.json`).
- `expectedPhrase` נכתב באותיות קטנות ובלי פיסוק — כך משווים אותו לזיהוי הדיבור.
  בתצוגה המערכת מוסיפה אות גדולה ונקודה.
- `game.type` יכול להיות `matching` (עם `wordIds`), `sentence-picture` או
  `fill-word` (שניהם עם `items`).

## החלפת האיורים

כל האייקונים והדמויות מצוירים ב-SVG בתוך `js/icons.js` ו-`js/characters.js`,
כדי שהאתר יעבוד אופליין ובלי תלות בשירות חיצוני. מי שירצה להחליף אותם
באיורים אחרים יכול לערוך את מחרוזות ה-SVG שם, או להחליף את `WordIcons.svg`
בטעינת קבצי תמונה. `preview-icons.html` מציג את כולם בעמוד אחד לבדיקה.
